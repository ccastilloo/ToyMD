# Teaching notebooks

Install the notebook dependencies from the repository root:

```console
python -m pip install -e ".[notebooks]"
python -m jupyterlab notebooks
```

Select the Python environment where ToyMD is installed as the notebook kernel.

| Notebook | Topic |
| --- | --- |
| `lab1.ipynb` | Microcanonical entropy of a harmonic oscillator |
| `lab2.ipynb` | Canonical ensemble and Langevin dynamics |
| `lab3.ipynb` | Symmetric and asymmetric double-well models |
| `lab4.ipynb` | Free energy differences between potential wells |
| `talentos.ipynb` | Introductory exercises in Spanish |
| `Untitled-1.ipynb` | Exploratory scratch work |
